These authored additions are uncompiled and unrun. File existence, source hashes,
AST inventories and CI selection are not execution or migration acceptance.
Original Python tests remain until all applicable parity and package gates pass.

## Shared ownership and evidence

UTC file log and the existing descendant-owned capture with wall/idle limits.
The shared finite loopback Bot API observer verifies exact forms, uploads,
downloads, durable observations and request accounting. Held responses expose real

listener/runtime and empty capture storage. Failures retain fixture evidence.

Historical assertion cohorts reuse the same pinned Git corpus, AST definition
selector, bounded worker and delayed temporary-directory ledger. They execute
unchanged admitted original definitions, not native algorithms as their oracle.
Cleanup acknowledgements, exact method collection, patch restoration and bounded
artifact inventories are required before success-only cleanup. Expected counters
below are authored assertions, not observed runtime results.
